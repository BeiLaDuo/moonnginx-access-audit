# 代码统计基线

本仓库由用户创建，原有两次提交；第二次提交
`1fc7d9c7e57f891838b560cb25248f1693808804` 上传了首轮交付代码。
`tools/measure_code.py` 默认使用这个实际存在于当前仓库历史中的提交
比较后续变化，使全新 CI 环境和交付 Git bundle 都可以复现统计。

原来的 MoonCIDR Audit v0.1.2 属于另一个保留的旧仓库，其提交不能被
冒充为本仓库的祖先。既有源码、后续有效实现、测试、示例和编译兼容
声明分别统计；首轮上传所含功能不再记为上传后新增代码。

4,000 行检查针对整个项目的有效 MoonBit 实现。新增差值只表示基线
之后的源码变化，格式化换行仍可能影响物理行数，不等同于算法增长。
可通过 `--baseline` 指定本仓库中的其他已知提交进行比较。
